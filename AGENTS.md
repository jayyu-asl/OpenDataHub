## Agent skills

### Issue tracker

Release specs and decision tickets live as GitHub issues in `jayyu-asl/OpenDataHub`, driven by the `gh` CLI. The consolidated product baseline is root `PRD.md`. See `docs/agents/issue-tracker.md`.

### Product and release planning

Before creating a version map or resolving its decisions, read `PRD.md` and follow its **Version maps and change control** section. Pin the accepted PRD revision and trace scope/acceptance to its requirement identifiers; use linked decision tickets for rationale and evidence.

### Triage labels

Five canonical triage roles map 1:1 to same-named labels: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `GLOSSARY.md` at the repo root plus `docs/adr/`. See `docs/agents/domain.md`.
